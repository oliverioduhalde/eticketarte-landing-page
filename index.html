✦ OBRA ÚNICA ✦

Una transacción se convierte en obra.
Un espectador presiona un botón.
El sistema selecciona un prompt, un algoritmo, una regla generativa.
En segundos, una pieza única e irrepetible se imprime sobre papel térmico.

Autoría compartida entre inteligencia artificial y artistas.
Destinada a desaparecer.

◆ CARACTERÍSTICAS TÉCNICAS

  • ▸ Modular y Replicable:
    Construcción de bajo costo. Raspberry Pi, Python, impresora térmica. Cualquier institución puede armar su propia copia.
  • ▸ Autoría Abierta:
    Artistas, investigadores, docentes cargan sus propios prompts y algoritmos. El sistema no jerarquiza autorías.
  • ▸ Offline o Conectado:
    Funciona autónomo sin internet, o conectado a APIs de IA generativa según necesidad.
  • ▸ 203 DPI de Precisión:
    Límite como potencia. Dos colores. Síntesis visual absoluta. Haikus gráficos.
  • ▸ Efimeridad Conceptual:
    Papel térmico condenado a desvanecerse. Promueve atesoramiento de instantes.

◆ ESPECIFICACIONES

HARDWARE Y SOFTWARE

Controlador: Raspberry Pi 4
Programación: Python 3.x
Impresora: Térmica USB · 203 DPI
Interacción: 1 botón físico
Generación: API o algoritmo local
Salida: Obra única · Papel efímero
